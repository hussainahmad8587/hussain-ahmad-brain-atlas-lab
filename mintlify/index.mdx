# Explore the brain in 3D

Brain Atlas Lab is an independent learning project for exploring neuroanatomy. Rotate the model, select a structure, and follow its notes to connect anatomy with its location and role.

## Start exploring

The interactive viewer is published separately from this guide. Open the Brain Atlas Lab app from the project’s app link when it is configured by the site owner.

In the viewer, begin with **Whole brain**, then select the hippocampus from the Atlas Index. Rotate the model and increase dissection to see how deeper structures sit within the brain.

## A note about the anatomy

The 3D meshes are sourced from BodyParts3D under CC BY 4.0. The structure notes are original educational summaries. This project is separate from ADNI repositories and contains no participant data.
